Question file format

QBank imports a set of questions from one JSON file. You can write the file by hand or ask an AI chat to write it. This page lists what a file may hold and what makes the importer refuse it.

Source of truth. This page describes the import check of the QBank API, which is the single source of truth for the format. If this page and the importer ever disagree, the importer is right, and its message names the question and the field to fix. Last checked against the importer on 2026-11-22.

The file

The file is one JSON object. A bare list of questions also works; it becomes a set titled “Imported questions”. A single code fence (```json … ```) around the JSON is ignored, so you can paste an AI chat’s reply as it is.

FieldMeaning
titleThe set’s name. Optional; “Imported questions” when missing. You can change it when you import.
descA short description. Optional.
kind"practice" (the default) or "exam". Questions of an exam set are asked only on exams. Any other value is refused.
questionsThe list of questions. Required, and it must not be empty.
termsOptional glossary: an object whose keys are term ids and whose values are ["Term", "Meaning"]. A question lists the term ids it uses.

Every question

Every question is an object with a type (one of the nine below) and an ask. Only ask is required.

FieldMeaning
typeRequired. One of single, priority, sata, highlight, order, match, matrix, matrixmulti, cloze.
askRequired. The question itself, as text. A missing or blank ask is refused.
stemOptional. The scenario or context before the ask. Missing is fine; it is kept as empty text, and the screen hides it.
rationaleOptional. The explanation shown after the answer. Missing is fine.
takeawayOptional. A one-line lesson. Missing is fine.
idOptional. A short text or number that names the question in messages and in twinOf. Questions without one are numbered Q1, Q2, … by position.
topic, wkOptional text: a topic label and a week label.
cj, need, srcOptional text labels: cj and need are free-form tags, and src names where the question came from.
diffOptional whole number (a difficulty).
termsOptional list of term ids from the file’s terms. An id with no definition is skipped, with a warning.
twinOfOptional, in an exam set only: the id of the practice question this one is the exam twin of.
table, imagesOptional. A table or pictures shown with the question. See below.

stem, rationale and takeaway must be text when they are present. A section written as a number or a list is refused.

Any other field you add is kept with the question and otherwise ignored.

The nine question formats

Where a format lists why, it is an optional short explanation for that choice, shown after the answer.

TypeShows asFields and rules
singleSingle answeroptions: at least 2, each {"t": "text", "ok": true, "why": "..."}. Exactly one option has "ok": true.
priorityPriority / first actionThe same as single: at least 2 options, exactly one with "ok": true.
sataSelect all that applyAt least 2 options, at least one with "ok": true. Every option may be correct.
orderOrdered responseitems: at least 3, each {"t": "text"}, written in the correct order.
matchMatchingpairs: at least 2, each {"l": "left", "r": "right"}. Optional extra: right-hand choices that match nothing, each {"r": "text"}.
matrixMatrixcolumns: at least 2 different names. rows: at least 1, each {"t": "text", "ans": "column name"} with exactly one right column. A column such as “Both” or “All of the above” gives a warning: use matrixmulti instead.
matrixmultiMatrix, check all that fitcolumns: at least 2 different names. rows: at least 1, each {"t": "text", "ans": ["column", "column"]} with at least one right column, each named once. Not every box of the table may be right. A warning if the ask does not say a row can fit “more than one” column.
highlightHighlightsegments: at least 3 phrases, in reading order, each {"t": "text", "ok": true}. Some segments are correct and some are not.
clozeDrop-downcloze: {"text": "... {0} ... {1} ...", "blanks": [...]} with one {0}, {1}, … placeholder per blank. Each blank is {"opts": ["a", "b"], "ans": 0}: at least 2 options, and ans is the index of the right one.

Tables and pictures

table is {"caption": "...", "head": ["A", "B"], "rows": [["1", "2"]]}. rows is required and must hold at least one row; caption and head are optional. Cells are text, numbers or true/false, and short rows are padded.

images is a list of at most 4 pictures per question. Each is an object with:

  • alt: required, a short description of what the picture shows.
  • Exactly one of src (a base64 data URL of a PNG, JPEG, WebP or SVG image) or svg (SVG markup as text).
  • caption: optional text.
  • at: "stem" (the default, shown under the question) or "rationale" (shown after the answer).

An image may be at most 300 KB after decoding. An SVG may not hold a script, an event handler or a link to another file. A table or picture the app cannot draw is refused, so a file never imports something you cannot see.

Warnings and errors

Errors block the import, and nothing is saved until you fix them. Each error starts with the question’s position and id, for example Question 3 (q3): missing ask. Warnings do not block the import. They tell you about, for example, a term with no definition, a twinOf outside an exam set, or a question that lacks cj, need, diff or src when other questions in the file use that field.

An example

{
  "title": "Basic geography",
  "desc": "Capitals and a little more.",
  "questions": [
    {
      "id": "g1",
      "type": "single",
      "ask": "What is the capital of France?",
      "options": [
        { "t": "Paris", "ok": true },
        { "t": "Lyon", "why": "A large city, but not the capital." },
        { "t": "Marseille" }
      ],
      "rationale": "Paris has been the capital for centuries."
    },
    {
      "id": "g2",
      "type": "single",
      "ask": "The Nile flows north.",
      "options": [
        { "t": "True", "ok": true },
        { "t": "False" }
      ]
    },
    {
      "id": "g3",
      "type": "order",
      "ask": "Put these in order from smallest to largest.",
      "items": [
        { "t": "Pond" },
        { "t": "Lake" },
        { "t": "Sea" }
      ]
    }
  ]
}
